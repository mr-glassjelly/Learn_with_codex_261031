# Friction 디자인 목업

빌드나 패키지 설치 없이 `dist/index.html`을 브라우저에서 열면 됩니다.

- `dist/index.html` — 상단 탭, 세 편지 카드 묶음, 편지 본문 창
- `dist/style.css` — 560px 중앙 화면과 반응형 디자인
- `dist/app.js` — 각 묶음의 카드 이동, 본문 열기, 오른쪽 설명 연동
- `dist/study.html` — 기존 서재를 재사용하는 독립 MY 화면
- `.openai/hosting.json` — 기존 Sites 링크의 정적 배포 설정

홈에는 오늘 도착한 편지 / 일곤의 뉴스레터 / 읽어볼 만한 편지가 순서대로 이어집니다.
기록함은 작성 날짜별 편지 묶음을 최신순으로 보여주며, MY에는 기존 서재가 표시됩니다.

로컬 서버: `python3 -m http.server 4173 --directory dist`

상단은 로고·검색창·메뉴의 3단으로 시작하며, 스크롤하면 메뉴와 돋보기만 남습니다. 검색창은 디자인 시연용입니다.

편지 표시 규칙:
- 누구에게: 필수, 새 편지의 기본값은 비어 있음. 예시 참고값은 “금방 보고 싶은 영희에게”, “사랑하는 부모님께”, “시작이 두려운 @수신자 님께”.
- 제목: 선택, 기본값과 참고값은 비어 있음. 제목이 있으면 받는 사람은 작게, 제목은 크게 표시.
- 언제, 누가: 필수, 기본값은 “@발신자 드림”. 날짜 표현을 포함한 맺음말도 사용 가능.
- 표지 우하단: 발신자, 그 아래 필요한 경우 보낸 곳을 작게 표시.

MY에서 작성한 기록은 기록함 탭을 열 때 날짜별 묶음에 반영됩니다.

편지 묶음은 오른쪽으로만 겹쳐 표시됩니다. 가운데 표지를 누르면 열리고, 오른쪽 편지 클릭·좌우 스와이프·키보드 좌우 방향키로 이동합니다. 다음으로 넘기면 앞 표지는 왼쪽으로 흐려져 사라지고, 다음 표지가 오른쪽에서 커지며 앞에 놓입니다. 세로 스크롤은 유지됩니다.

디자인 마무리: Impeccable의 polish 지침과 정적 검사기를 적용했습니다. 기존 편지 구조를 유지하며 본문·보조 글자 대비, 터치 영역, 글자 크기와 간격을 정리했습니다. 스킬과 엔진은 임시 작업 폴더에서 사용하며 사이트의 실행 의존성에는 포함하지 않습니다.
